### [openFDA Regulatory DataOps Control Tower](https://github.com/sairajkashid-prog/openfda-regulatory-dataops-control-tower)

A real-data operations project integrating official FDA drug-enforcement and drug-shortage records.

- Processes 1,000 recent enforcement records and 1,651 shortage records
- Monitors schema changes and source freshness
- Applies severity-based data-quality checks
- Quarantines invalid records with exact reasons
- Links datasets using exact package NDC identifiers
- Detects inserted, changed and unchanged records
- Produces SQL, Excel, HTML and Streamlit reporting
- Includes 12 automated tests and GitHub Actions
- Achieves 91.43% measured code coverage

**Real-data results:** 44 recall numbers had exact shortage-dataset NDC matches, including 24 with unavailable or limited-availability rows.

[View Live Regulatory Report](https://sairajkashid-prog.github.io/openfda-regulatory-dataops-control-tower/)

> The project is for analytical learning only. An NDC match does not prove that a recall caused a shortage, and the dashboard is not a medical or public-safety alerting system.
