## Featured Project

### [Pharma Sales ETL & Data Quality Pipeline](https://github.com/sairajkashid-prog/pharma-sales-etl-quality-pipeline)

A Python and SQL portfolio project that:

- Processes synthetic pharmaceutical sales data
- Applies 13 data-quality checks
- Separates accepted and rejected records
- Loads validated data into SQLite
- Uses SQL joins, CTEs and window functions
- Generates Excel, HTML and Streamlit reports
- Runs automated tests using GitHub Actions

### Sample Results

- **5,050** source rows
- **4,650** accepted records
- **400** rejected records with reasons
- **92.08%** data-quality pass rate
- Exact source-to-target reconciliation
- Zero duplicate records in the final warehouse
